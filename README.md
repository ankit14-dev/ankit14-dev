## 💼 Experience

### GrabnGO — Software Engineering Intern

During my internship, I worked on **Mahavira Electricals**, an e-commerce platform for electrical products.

Some of the things I worked with:

* ⚡ Next.js frontend
* 🔧 Node.js microservices
* 🗃️ DynamoDB product infrastructure
* 🔎 OpenSearch semantic/product search
* ☁️ AWS infrastructure
* 🖼️ Product data & image pipelines
* 🧠 Search designed to understand queries rather than simply match strings

The fun part was getting to work across the entire stack:

```text
Product Data
     ↓

     ↓

     ↓

     ↓
Frontend
     ↓
Actual Users
```
